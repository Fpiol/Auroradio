# Auroradio

Auroradio 是一款沉浸式桌面音乐播放器，把天气电台、歌词舞台、粒子视觉和 3D 歌单架组合成一个更接近现场感的私人音乐空间。支持 macOS 与 Windows。

> 本项目基于 [Mineradio](https://github.com/XxHuberrr/Mineradio)（作者 XxHuberrr）二次开发，遵循 GPL-3.0 授权。感谢原作者。

## 核心特性

- 天气电台：根据当前位置、城市和天气生成更合适的播放队列
- 搜索、每日推荐、私人电台、继续听、听歌画像和我的歌单
- 播放态视觉系统：粒子舞台、歌词舞台与电影镜头同步
- 面向长播客和 DJ 曲目的专属视觉模式
- 歌词舞台、自定义歌词、歌词位置与视觉控制
- 自定义专辑封面上传与裁剪
- 右键唤起 3D 歌单架，支持歌单队列浏览
- 网易云音乐、QQ 音乐账号搜索、歌单、播客接入
- 本地隐私中心：登录态、缓存、视觉存档只保存在本机，可一键清理

## 开发运行

```bash
npm install
npm start
```

## 构建安装包

```bash
npm run build:mac   # macOS Universal (Intel + Apple Silicon)
npm run build:win   # Windows x64
```

产物位于 `dist/`。

## 第三方音乐平台说明

Auroradio 不是网易云音乐、QQ 音乐或腾讯音乐娱乐集团的官方客户端，也不隶属于任何音乐平台。第三方平台接入仅用于个人学习、本地客户端体验和用户自有账号的播放辅助，请遵守对应平台的用户协议与版权规则。项目不提供绕过付费、会员或音质限制的能力。

## 隐私

登录 Cookie、搜索历史、自定义封面、自定义歌词和节奏缓存只保存在本机用户数据目录或浏览器本地存储，不会提交到仓库。
